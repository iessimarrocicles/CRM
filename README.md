# AI Agency CRM 🚀

> **CRM personalizado para agencias de Inteligencia Artificial y Automatización.**

Este proyecto es una plataforma diseñada para que agencias de IA gestionen su cartera de clientes, proyectos de automatización, despliegue de agentes inteligentes y consumo de recursos de LLMs.

---

## 🔒 Aviso de Seguridad (Repositorio Público)

Este repositorio es **público**. Todo el equipo y los agentes de IA colaboradores deben seguir rigurosamente las pautas de seguridad detalladas en [agents.md](file:///c:/Users/Kike/Desktop/CRM/agents.md).

- **NUNCA** subas archivos `.env` o credenciales a GitHub.
- Todas las credenciales y claves de Firebase o proveedores de IA deben mantenerse en archivos de entorno locales (ignorados por `.gitignore`) o en un gestor de secretos.
- Consulta [.env.example](file:///c:/Users/Kike/Desktop/CRM/.env.example) para conocer la estructura de configuración requerida.

---

## 🛠️ Pila Tecnológica Prevista

- **Backend & Cloud:** [Firebase](https://firebase.google.com/) (Authentication, Cloud Firestore, Cloud Storage, Cloud Functions)
- **Frontend / Fullstack:** Next.js / React con TypeScript
- **Integraciones de IA:** OpenAI, Anthropic Claude, Google Gemini
- **Estilos:** Tailwind CSS / UI Components

## 🚀 Inicio Rápido

1. **Clonar el repositorio:**
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd CRM
   ```

2. **Configurar variables de entorno:**
   Copia el archivo de ejemplo y completa los valores con tus credenciales de desarrollo:
   ```bash
   cp .env.example .env.local
   ```

   *(Se actualizará a medida que se defina la estructura de la aplicación)*
